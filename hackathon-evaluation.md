## What to Build

An AI agent on Gemini + Google Cloud that:
- Takes a goal, makes a plan, and carries out multi-step tasks autonomously
- Removes everyday friction at work, home, or across an enterprise
- Uses Google's Agent Development Kit (ADK)

## Tracks

1. **The Taskmaster** — agents that handle heavy lifting of massive datasets and automate complex workflows asynchronously
2. **The Collaborative Partner** — agents that work alongside humans
3. **The Fortified Enterprise Fleet** — enterprise security/compliance agents

## What to Submit

- Demo video

- Architecture diagram
- Short write-up

## Strategic Fit

**Best track for our skills:** The Taskmaster — our CallbackOps product IS an async agent that handles lead recovery workflows. We can build a Gemini-powered version of the lead-recovery agent and submit it.

**Idea:** Build a "Lead Recovery Agent" that:
1. Monitors missed calls and web inquiries (simulated input)
2. Qualifies the lead using Gemini
3. Drafts an approved response
4. Books or routes the next step
5. Logs everything to a status board

This doubles as:
- A hackathon submission ($50K potential prize)
- A productized service we can sell (CallbackOps)
- A portfolio piece for Contra/freelance work
